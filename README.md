# Champion Starter Kit

Everything a GSD project champion needs to know, in <5 minutes.

**Live site:** [champion-starter-kit.quick.shopify.io](https://champion-starter-kit.quick.shopify.io)

## Files

| File | What it is |
|------|-----------|
| `index.html` | The Quick site -- principles, playbook, cheat sheets |
| `gsd-champion-skill.md` | Portable AI skill for Claude Code, Cursor, Mana, etc. |

## Making changes

1. Edit files directly on GitHub or clone locally
2. Merge to `main`
3. Run `./deploy.sh` to push to Quick (requires Quick CLI + Google auth)

```bash
./deploy.sh "your commit message"
```

GitHub Pages updates automatically on push. Quick requires the manual deploy step.
